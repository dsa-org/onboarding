# StatLink - Basic Application Workflow

This workflow is designed to get you from **zero → rankings → insights → decisions** as quickly as possible.

This is a **quick run-through (~10–15 min)** to understand how StatLink works end-to-end.

## Manager Dashboard Workflow

### 1) Setup Your Environment

- [ ] **Access the Application**  
  Visit [www.staging.statlink.io](https://staging.statlink.io/)  
  - *Note:* This is the testing environment. Remove `staging` for production.

- [ ] **Create an Account**  
  Select your role as **Coach**

- [ ] **Create a Team**  
  Use: **Saint Joseph's Hawks**

✅ **Outcome:** You now have a team environment ready for data

---

### 2) Build Your Roster + Staff

- [ ] **Upload a Roster**  
  - Path: **Home > Roster > Players > Upload Roster**  
  - Upload manually or via CSV  
  - [Download sample roster](../sample_files/StatLink-Roster-SJU.csv)

- [ ] **Invite a Manager**  
  - Path: **Home > Roster > Manager > Invite Manager**

✅ **Outcome:** You now have players and staff in the system

---

### 3) Define How You Evaluate Players

- [ ] **Create a Custom Scorecard**  
  - Path: **Data Entry > Create Custom Scorecard**  
  - Add metrics, characteristics, and outcome types  

👉 This defines how rankings are generated.

✅ **Outcome:** You now have a framework for evaluating performance

---

### 4) Collect Data

- [ ] **Submit Data Using Scorecards**  
  - Log player performance using your scorecard  
  - Open a submission to view:
    - **Player Rankings**
    - **Submission Details**

✅ **Outcome:** Rankings should now populate based on your inputs

---

### 5) (Optional) Enrich with External Data

- [ ] **Upload Data from Integrations**  
  Import external data to improve ranking accuracy and depth.

  - Supported: Catapult, Wyscout, PlayerData, NCAA stats  
  - Combines tracking data + match stats + evaluations  

  **Sample Files:**
  - [Catapult Data Sample](../sample_files/Catapult-Export-SJU-Oct-29.csv)
  - [Wyscout Report Sample](../sample_files/Duquesne_Duke_Saint_Josephs_Hawks_2_1.pdf)

  **Note:** Requires Premium access

- [ ] **Review Uploaded Data**  
  - Validate inside **Submission Details**

✅ **Outcome:** Your dataset is now richer and more predictive

---

### 6) Analyze + Make Decisions

- [ ] **Explore the Analysis Tab**  
  Use these tools to identify top performers:

  - **Player Trends** → performance over time  
  - **Player Rankings** → top vs bottom performers  
  - **Depth Chart** → roster structure  
  - **Master Submission List** → full dataset  
  - Generate a **Team Report**

✅ **Outcome:** You can now identify top players and trends

---

### 7) Multi-Team + Navigation

- [ ] **Join an Existing Team**  
  - [Join Existing Team](https://staging.statlink.io/login/MHDRF87/Manager)

- [ ] **Switch Teams**  
  - Use the **Team Selector** (top-right)

---

## Player Profile Workflow

### 1) Create + Build Profile

- [ ] **Create a Player Profile**  
  - Path: **Player Selector > Player Tab > + Button**  
  - Upload photo + complete profile

- [ ] **Complete the ABOUT ME Tab**  
  Add:
  - Bio, contact info, career history  
  - Academic interests  
  - Events + highlight videos  

---

### 2) Share + Promote

- [ ] **Share Player Profile**  
  - Use **Share Profile**
  - Open link to view **FlashStat**
  - Send to college coaches using email template

✅ **Outcome:** Player profile is now shareable and market-ready

---

### 3) Ownership + Data

- [ ] **Add an Additional Owner**  
  - Path: **Account > Add Owner**

- [ ] **Self-Enter Data**  
  - Path: **Data Entry > Enter Data**  
  - Example: log a fitness test

---

## Search + Discovery

- [ ] **Use Filters to Discover Players**  
  Filter by:
  - Sport, Position, Height, Score Range

- [ ] **Search Players or Teams**

- [ ] **Engage with the Market**
  - Follow players or teams  
  - Add players to your team  
  - Contact players  

---

## ⚡ What You Should Have Now

By completing this workflow, you should:

- Have a full roster uploaded  
- Be collecting and viewing player data  
- See rankings and trends  
- Understand how to evaluate players  
- Be able to share player profiles
